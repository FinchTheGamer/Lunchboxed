# Lunchboxed
This is my very first Unity project! Its all about learning the ropes of Unity, so I expect this to take much longer than reasonable due to both time crunches and a lack of skill. 


How To Play:

Its easy! Arrow keys to move, as most platformers, but feel free to use the space bar to jump as well! Collect chips, the little floating objects, and you'll gain a score! It doesn't do anything for now...
Get to the green flag to get to the next level! Get to the purple flag to win (win screen sold seperately).

Why I built this:

I built this because I want to become a programmer. I could listen to a tutorial... or I could throw myself into the deep end instantly! I chose the latter. Did I have headaches? Yes! Is something published! Indeed!

How this was built:
This was built via the Unity Game Engine. I used C#.
